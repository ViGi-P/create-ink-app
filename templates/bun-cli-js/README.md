### This project was bootstrapped using [@vigi-p/create-ink-app](https://www.npmjs.com/package/@vigi-p/create-ink-app).

#### Commands

|                                              | npm             | yarn             | pnpm             |
| -------------------------------------------- | --------------- | ---------------- | ---------------- |
| Dev                                          | `npm run dev`   | `yarn run dev`   | `pnpm run dev`   |
| Lint                                         | `npm run lint`  | `yarn run lint`  | `pnpm run lint`  |
| Tests                                        | `npm run test`  | `yarn run test`  | `pnpm run test`  |
| Build                                        | `npm run build` | `yarn run build` | `pnpm run build` |
| Create symlink (Run the build command first) | `npm link`      | `yarn link`      | `pnpm add -g .`  |
