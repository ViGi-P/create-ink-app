# Contributing to create-ink-app 🚀

Thank you for considering contributing to `create-ink-app`! We welcome all contributions, from bug fixes to new features and improved documentation.

## 🛠 Development Setup

1.  **Clone the repository:**

    ```sh
    git clone https://github.com/vigi-p/create-ink-app.git
    cd create-ink-app
    ```

2.  **Install dependencies:**
    This project uses `pnpm`.

    ```sh
    pnpm install
    ```

3.  **Build the project:**
    ```sh
    pnpm run build
    ```

## ✅ Testing

Before submitting a pull request, please ensure all tests pass:

```sh
pnpm test
```

We also use `xo` for linting:

```sh
pnpm run lint
```

## 📝 Contribution Workflow

1.  **Fork the repo** and create your branch from `main`.
2.  **Add tests** for any new features or bug fixes.
3.  **Ensure the build passes** and code matches the project style.
4.  **Open a Pull Request** with a clear description of your changes.

## 🤝 Code of Conduct

Please be respectful and professional in all interactions within this project.

Happy coding!
